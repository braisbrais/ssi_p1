### Apartado 12.c

Cread un nuevo contenedor cifrado de 20 MB y guardadlo con el nombre `contenedor_cifrado`.

- Definid una contraseña segura.
- Configurad protección adicional con un *keyfile*. ¿En qué consiste esta opción? ¿Cómo funciona?

#### Respuesta 12.c

* [x] Creado el contenedor cifrado de 20 MB con el nombre `contenedor_cifrado` <!-- CASILLA 12.c -->

<!-- INICIO RESPUESTA -->
Un keyfile es un archivo cuyo contenido VeraCrypt utiliza como parte de la clave para desbloquear el volumen. Al montarlo, hay que proporcionar la contraseña y seleccionar el mismo archivo; VeraCrypt combina ambos elementos para derivar la clave de cifrado. Por tanto, conocer solo la contraseña no basta si el volumen está configurado para usar un keyfile.

El archivo puede contener datos existentes o generados aleatoriamente. Es importante conservarlo sin modificar: si se pierde o cambia, no se podrá acceder al volumen, aunque se recuerde la contraseña.

### Apartado 12.e

¿Es posible recuperar una contraseña de un contenedor cifrado de VeraCrypt? Explicad la respuesta.

#### Respuesta 12.e

<!-- INICIO RESPUESTA -->
No existe un mecanismo de VeraCrypt que permita recuperar o restablecer una contraseña olvidada. La contraseña y, si se configuró, el archivo-clave se utilizan para derivar la clave que permite descifrar el volumen; sin las credenciales correctas, los datos no se pueden descifrar. Un archivo-clave perdido o modificado también impide acceder al volumen.

<!-- FIN RESPUESTA -->
